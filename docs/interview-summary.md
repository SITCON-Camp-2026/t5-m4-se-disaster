# Main Agent 訪談彙整

> 這份文件是 Codex 根據三個 subagent persona 回饋產生的彙整草稿。請人類成員至少刪改一處，並在「我自己補充的判斷」或「小隊討論後的補充」留下確認痕跡。

## 三個 persona 的共同需求

- 使用者明確說的：三個角色都需要清楚分辨「原始資訊」「候選整理」「已確認事實」。
- 使用者明確說的：三個角色都擔心轉述、模糊地點、缺時間或缺確認窗口的資訊被直接變成任務。
- 使用者明確說的：畫面需要提醒哪些資訊需要人工確認，以及為什麼目前不能直接行動。
- 使用者明確說的：三個角色都指出「讚 / 優先 / 最新 / 已整理草稿」可能被誤解成可信、急迫或可以行動。

## 三個 persona 之間的衝突需求

- 回報者希望可以快速留下不完整資訊；資訊整理者需要足夠脈絡才能降低誤判。
- 行動者希望快速知道可不可行動；資訊整理者反而需要避免畫面太早產生「可以行動」的暗示。
- 回報者不想被表單阻擋；整理者和行動者需要知道來源、時間、地點、當事人與確認狀態。

## Phase 0 原型中被推翻的假設

- 原本假設：把資料做成「最新資料」排序可以幫使用者更快處理。
  - 被什麼回饋推翻：三個 subagent 都擔心「讚 / 優先」被誤解成可信或急迫；行動者也指出「最新資料」不一定代表狀態真的最新。
- 原本假設：候選類型能幫使用者理解資料。
  - 被什麼回饋推翻：資訊整理者和行動者都指出「任務候選」可能讓人太快把草稿當成任務。
- 原本假設：「已整理草稿」的文字足以避免誤解。
  - 被什麼回饋推翻：三個 subagent 都提到「已整理」容易被看成已處理、已查過或可以交給下一位協作者使用。

## 最容易造成誤導的風險

- 最危險的是把整理進度或注意力排序誤看成查核結果，例如「已整理草稿」「最新」「優先」「讚」被理解成已確認、比較急或可以出發。
- 其次是 AI 或人類把原文沒有說清楚的地點、數量、身份或行動建議補成確定事實。

## 可以考慮的設計方向

> 這裡只是可考慮方向，不是標準答案。

- 可以讓每筆資料先顯示「現在不能直接做什麼」與「缺少哪些資訊」，再顯示可能整理方向。
- 可以把來源取得方式、查核狀態、整理進度、行動狀態拆開呈現，避免混在同一個標籤裡。
- 可以在候選整理旁保留「原文依據」與「推測 / 人類修正」欄位，讓下一位協作者能追溯判斷來源。
- 可以重新檢查「已整理的」「任務候選」「優先」這些字是否太像正式狀態。

## 需要人類決策的取捨

- 取捨 1：
  - 選項 A：讓回報者快速送出不完整資料。
  - 選項 B：要求更多欄位，讓整理者和行動者比較安全。
  - 我目前傾向：AI 草稿傾向先服務資訊整理者，讓不完整資料可以存在，但不能被包裝成可行動任務。
  - 理由：Phase 0 的學習目標是看見混亂與不確定性，資訊整理者最能承接這個任務；但這需要人類確認。
- 取捨 2：
  - 選項 A：用「任務候選」幫使用者快速理解可能方向。
  - 選項 B：減少任務語氣，先顯示缺口和風險。
  - 我目前傾向：AI 草稿傾向減少正式任務語氣。
  - 理由：三個 persona 都擔心未確認資訊被過早行動化。

## 不應該讓 AI 自動決定的事情

- AI 不應該自動判斷一筆資訊已確認、可以派工或可以行動。
- AI 不應該自動補真實地點、真實人物、電話、數量或現場安全狀態。
- AI 不應該把「可能」「疑似」「轉述」改寫成確定描述。

## 我採用的 AI 整理

- 採用「使用者會把排序、整理進度、查核狀態混淆」這個風險整理，因為它直接對應目前首頁與工作台文案。
- 採用「v1 應優先保護原文和人工確認」這個方向，作為後續討論起點。

## 我不採用的 AI 建議

- 建議：直接把 persona 回饋整理成一串功能待辦。
  - 不採用原因：Release 01 是需求分析，不是實作階段；現在應先保留衝突與取捨，不要太快變成 UI 清單。
- 建議：把「行動者」當成主要使用者並凸顯可行動項目。
  - 不採用原因：目前資料多數仍未確認，太早服務行動者可能強化誤判風險；是否採用仍需人類決策。
- 建議：把「讚 / 優先」視為單純排序小功能，不列為需求風險。
  - 不採用原因：三個 subagent 都提到它可能被誤解，應保留為 v1 討論重點。

## 我自己補充的判斷

- 待人類確認：目前 prototype 最需要改善的可能不是新增功能，而是降低「候選」被看成「已確認」的視覺暗示。
- 待人類確認：小隊可以討論首頁是否應繼續叫「最新資料」，或改成更不暗示可信度的說法。
- 待人類確認：小隊可以決定「已整理的」是否要改成更明確的草稿語氣，例如「整理草稿」或「待確認整理」。

## 我仍不確定的地方

- 不確定 v1 是否要真的支援回報者輸入，還是只整理 Phase 0 原始資訊。
- 不確定「優先」在課堂中是有用的注意力排序，還是會造成可信度誤解。
- 不確定小隊是否同意把資訊整理者作為 v1 主要服務對象。
